# Holidaze

Holidaze is an accommodation booking app. It lets visitors browse venues, search and filter results, view venue details, and book stays. Logged-in users can manage their profile, bookings, and venues when they have manager access.

- Live website: [https://holidaze-project-exam2.netlify.app/](https://holidaze-project-exam2.netlify.app/)

## Built With

- Next.js
- React
- TypeScript
- Tailwind CSS
- Zustand
- Zod

## Getting Started

1. Clone the repo:

```bash
git clone https://github.com/Andy19955/Project-Exam-2.git
```

2. Navigate to the project directory:

```bash
cd Project-Exam-2
```

3. Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Configuration

Create a `.env` file in the project root and add your API key:

```bash
NEXT_PUBLIC_API_KEY=your_api_key_here
```

This is used for local development. The file should not be committed to version control.

## Scripts

- `npm run dev` - start the development server
- `npm run build` - build the app for production
- `npm run start` - start the production server
- `npm run lint` - run ESLint
